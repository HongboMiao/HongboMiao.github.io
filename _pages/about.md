- *2025.07 - 2025.09*，Batch To Batch 通信算子传输优化，腾讯犀牛鸟开源人才培养计划  
  面向 HBM 10K 离散块（128B–2MB）跨主机搬运场景，搭建端到端传输模块与一致性校验流程；实现批包与块处理优化、多通道并行、自适应动态切换发送/接收 API 的系统应用；全流程总耗时由 **194.64s** 降至 **152.69s（1.27×）**，大块 2MB 单轮耗时由 **10.78s** 降至 **7.29s（1.48×）**。  
  取得荣誉：腾讯犀牛鸟开源人才培养计划开源贡献者、任务奖金获得者、优秀学生。[[News]](https://blog.csdn.net/tencent__open/article/details/151729620)

- *2025.10 - 至今*，多模态融合应用，电子科技大学大数据研究中心  
  融合负荷历史序列与天气、节假日等外生特征构建多变量预测数据集；设计特征对齐与注意力融合方法，并系统比较 Transformer、LSTM、TCN 等模型在不同预测跨度下的表现（MAPE / MAE / RMSE）。

- *2025.11 - 至今*，千万核可扩展公里级海陆气耦合区域气候模式及预测系统，国家超级计算无锡中心

- *2025.12 - 2026.03*，GWBP：面向冷冻电镜重建的 GPU 加速加权反投影优化，青海大学  
  面向冷冻电子断层重建中的 Weighted Back-Projection（WBP）流程，开展 GPU 加速与系统级优化研究；通过 GPU kernel 化、任务批处理、资源复用与高效 stream 调度优化端到端 pipeline，减少不必要的数据传输、主机协调和写回阻塞，提升重建效率。与最先进的多核 CPU 实现相比，GWBP 将端到端运行时间从 **3.131** 秒减少到 **0.655** 秒，实现了最高 **4.78** 倍的加速。[[GitHub]](https://github.com/OptiYouth-Lab/GWBP)

- *2026.02 - 至今*，具身智能世界模型自适应精度推理优化，青海大学高性能与云计算实验室 
  基于不同模块对精度与误差传播的敏感性，设计分层精度分配策略，并结合中间激活复用、显存生命周期管理与推理流程优化，降低关键阶段的计算与存储开销；通过实验比较不同精度配置下的生成质量、吞吐与显存占用，提升模型整体推理效率。
